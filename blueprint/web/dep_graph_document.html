Corollary 4.1The prime number theorem with logarithmic savings

Let \(A \in \mathbb {N}\). For every real \(z \ge 2\),

\[ \sum _{n \le z} \Lambda (n) = z + O_A\! \left(\frac{z}{(\log z)^A}\right), \]

and for every integer \(q \ge 1\),

\[ \sum _{\substack {n \le z \\ (n, q) = 1}} \Lambda (n) = z + O_A\! \left(\frac{z}{(\log z)^A}\right) + O\big(\log q \cdot \log z\big), \]

the last error term having an absolute implied constant.

Definition 9.12Bump functions

A bump function is a function \(\nu : \mathbb {R}\to \mathbb {R}\) that is \(C^\infty \), supported in \([1/2, 2]\), non-negative, and normalised by \(\int _0^\infty \nu (t)\, \frac{\mathrm{d}t}{t} = 1\). Such functions exist by Proposition 9.11(1); one is fixed once and for all, and the implied constants in this section may depend on this choice. For \(\varepsilon {\gt} 0\) we write \(\widetilde{1}_\varepsilon \) for the smoothed cutoff of Proposition 9.11 built from \(\nu \); by that proposition, \(0 \le \widetilde{1}_\varepsilon \le 1\), \(\widetilde{1}_\varepsilon = 1\) on \((0, 1 - (\log 2)\varepsilon ]\), \(\widetilde{1}_\varepsilon = 0\) on \([1 + 2(\log 2)\varepsilon , \infty )\) when \(\varepsilon {\lt} 1\), and \(\mathcal{M}[\widetilde{1}_\varepsilon ](s) = s^{-1} \mathcal{M}[\nu ](\varepsilon s)\) for \(\Re s {\gt} 0\).

Definition 3.17The discrepancy \(\Delta _f\)

Let \(f : \mathbb {N}\to R\) with \(R\) a field (in practice \(R = \mathbb {R}\) or \(\mathbb {C}\)), let \(x \in \mathbb {R}\), \(q \in \mathbb {N}\) and \(a \in \mathbb {Z}/q\mathbb {Z}\). The discrepancy of \(f\) in the progression \(a \bmod q\) up to \(x\) is

\[ \Delta _f(x; q, a) := \sum _{\substack {n \le x \\ n \equiv a \pmod q}} f(n) - \frac{1}{\varphi (q)} \sum _{\substack {n \le x \\ (n, q) = 1}} f(n). \]

Here \(1/\varphi (0)\) is read as \(0\), so that for \(q = 0\) only the first sum survives; all estimates below assume \(q \ge 1\).

Definition 10.2The maximal Chebyshev error

For a real \(x\) and \(q \in \mathbb {N}\) set

\[ E(x; q) := \sup _{1 \le y \le x}\ \sup _{a \in (\mathbb {Z}/q\mathbb {Z})^*} \left| \psi (y; q, a) - \frac{y}{\varphi (q)} \right| \in [0, \infty ] . \]

Here \(y\) ranges over all of \([1, x]\), not only over \([\sqrt x, x]\), and \(x\) is an arbitrary real (no parameter datum is involved). For \(q \ge 1\), \(E(x; q) \ll x\) by Lemma 3.6, so \(E(x; q)\) is finite and equals the supremum of the same quantities taken in \(\mathbb {R}\).

Definition 3.25Maxima over \(y\) and over reduced residues

Fix a parameter datum. For a function \(F\) on \(\mathbb {R}\) with values in \([0, \infty ]\) we write

\[ \max _{\sqrt x \le y \le x} F(y) := \sup \{ F(y) : \sqrt{x} \le y \le x \} , \]

and for \(q \in \mathbb {N}\) and \(F\) a function on \(\mathbb {R}\times \mathbb {Z}/q\mathbb {Z}\) with values in \([0, \infty ]\),

\[ \max _{\substack {\sqrt x \le y \le x \\ a \in (\mathbb {Z}/q\mathbb {Z})^*}} F(y, a) := \sup _{a \in (\mathbb {Z}/q\mathbb {Z})^*} \ \sup _{\sqrt x \le y \le x} F(y, a) . \]

Both suprema are taken in \([0, \infty ]\), so they always exist, and the residue \(a\) ranges over the units of \(\mathbb {Z}/q\mathbb {Z}\) only. We apply this to \(F(y, a) = |\Delta _f(y; q, a)|\), and when \(y\) and \(a\) are clear from the context we abbreviate the left-hand side to \(\max _{y, a} |\Delta _f(y; q, a)|\). It is part of every estimate for such a maximum that the supremum is finite.

Definition 3.23Parameter datum

A parameter datum consists of real numbers \(x, U, V\) satisfying

\[ x \ge 2, \qquad UV \le \sqrt{x}, \qquad U \ge e^{\sqrt{\log x}}, \qquad V \ge e^{\sqrt{\log x}}. \]

Every statement in Chapters 6 to 10 that mentions \(x\), \(U\) or \(V\) without quantifying them is implicitly universally quantified over such a datum, and the implied constants in those statements never depend on the datum. The main theorem is proved by instantiating \(U = V = e^{\sqrt{\log x}}\) once \(x {\gt} e^{32}\) (Theorem 3).

Definition 3.4Chebyshev’s function in progressions

For a real number \(x\), a modulus \(q \in \mathbb {N}\) and a residue class \(a \in \mathbb {Z}/q\mathbb {Z}\), set

\[ \psi (x; q, a) := \sum _{\substack {n \le x \\ n \equiv a \pmod q}} \Lambda (n). \]

Definition 3.12Restriction

For an arithmetic function \(f\) and a set \(S \subseteq \mathbb {N}\), let \(f|_S\) denote the arithmetic function \(f|_S(n) := f(n) 1_{n \in S}\). For \(r \in \mathbb {N}\) we write \(f_r\) for the restriction of \(f\) to the integers coprime to \(r\):

\[ f_r(n) := f(n)\, 1_{(n, r) = 1} = \begin{cases} f(n) & \text{if } (r, n) = 1, \\ 0 & \text{otherwise.}\end{cases} \]

Note that \(f_1 = f\) and that \(f_0\) is supported on \(n = 1\) only, since \((0, n) = n\). The same notation is used for arbitrary functions \(f : \mathbb {N}\to R\) with \(R\) having a zero; when \(f\) is an arithmetic function the two readings agree.

Definition 3.3Sums over \(n \le x\)

For \(f : \mathbb {N}\to R\) with values in an additive commutative monoid and a real number \(x\), the summatory function of \(f\) is

\[ \sum _{n \le x} f(n) := \sum _{1 \le n \le \lfloor x \rfloor } f(n). \]

The term \(n = 0\) is never included, and the sum is empty (hence \(0\)) when \(x {\lt} 1\). Throughout, every sum of the form \(\sum _{n \le x}\) with a real endpoint \(x\) is to be read in this way, and a sum \(\sum _{n \le x, P(n)}\) with a side condition is the summatory function of \(f \cdot 1_P\).

Lemma 8.6Möbius expansion of \(1_r\) and \(\log _r\)

Definition 3.2Arithmetic functions

\(\mathbb {N}= \{ 0, 1, 2, \dots \} \) denotes the natural numbers, although all sums over \(n \le x\) start at \(n = 1\) (Definition 3.3). For \(a, b \in \mathbb {N}\) we write \((a, b) = \gcd (a, b)\), with the convention \((0, b) = b\). Dirichlet convolution is written \(f * g\); \(1\) denotes the constant function \(1\) on \(\mathbb {N}_{\ge 1}\) (so that \(f * 1\) is the divisor sum of \(f\)), \(\delta _1\) its convolution identity, \(\mu \) the Möbius function, \(\varphi \) Euler’s totient, \(\tau \) the divisor function and \(\Lambda \) the von Mangoldt function; \(\log \) also denotes the arithmetic function \(n \mapsto \log n\), and \(\log ^v\) its pointwise \(v\)-th power (with \(\log ^0 = 1\)). All arithmetic functions vanish at \(0\).

For \(q \in \mathbb {N}\) and \(a \in \mathbb {Z}/q\mathbb {Z}\) we write \(n \equiv a \pmod q\) for the natural numbers whose residue class modulo \(q\) is \(a\); when \(q = 0\) we identify \(\mathbb {Z}/0\mathbb {Z}= \mathbb {Z}\), and when \(q = 1\) every natural number lies in the single residue class. \((\mathbb {Z}/q\mathbb {Z})^*\) is the unit group, of order \(\varphi (q)\) for \(q \ge 1\). For a Dirichlet character \(\chi \) modulo \(q\) we write \(\chi _0\) for the principal character, \(\mathop{{\sum \nolimits ^{*}}}_{\chi \bmod q}\) for a sum over primitive characters, and \(\xi \uparrow ^q\) for the character modulo \(q\) induced by a character \(\xi \) modulo a divisor of \(q\), i.e. \((\xi \uparrow ^q)(n) = \xi (n) 1_{(n,q) = 1}\). Complex conjugation is \(\overline{z}\) and \(|z|\) is the absolute value, also for complex \(z\).

Notation 3.1Asymptotic notation and implied constants

For real-valued quantities \(f, g\) the statement \(f \ll g\) (equivalently \(f = O(g)\)) means \(|f| \le C g\) for some constant \(C {\gt} 0\); a subscript, as in \(f \ll _A g\), records the parameters the constant may depend on. Unless stated otherwise the constant may also depend on the implied constants of the two external inputs (Theorem 1, Theorem 2) and on the fixed bump function of Definition 9.12, but never on \(x, y, q, a, Q\) or on the parameter datum of Definition 3.23. Constants are not tracked in the formalisation: each \(\ll \) is witnessed by some real number and nothing is asserted about its size.

Theorem 2The large sieve inequality

For all real \(Q \ge 1\), all \(H \in \mathbb {Z}\), all integers \(N \ge 1\) and all \(c : \mathbb {Z}\to \mathbb {C}\),
