Chebyshev error $\psi(y; q, a) - y/\varphi(q)$ using the prime number theorem. Two small matters remain:
the parameter datum forces $x \ge e^{16}$, so the range $x \le e^{32}$ in which no admissible choice of
$U = V$ exists is handled by the trivial bound; and the maximum over $y$ in the main theorem runs
over all of $[1, x]$, while the estimates so far only cover $\sqrt x \le y \le x$.
